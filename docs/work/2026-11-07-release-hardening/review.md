## Findings
1. **KAF, not the library (confirmed from source).** `Krowi_AchievementFilter\Options\Options.lua:13` `SettingsPanel:Close(true)` (from the Settings stub's Open button, `Options\Window\Stub.lua:31`, and screenshot mode, `Options\General.lua:66`) runs `ExitWithCommit` → `Commit` → `CommitBindings` → `SaveBindings(GetCurrentBindingSet())` from KAF's code (`Blizzard_SettingsPanel.lua:224-268, 308-315`), firing `UPDATE_BINDINGS` tainted (as the accepted KAF #197), and commits the visit's applied settings from addon code; `HideUIPanel` is a plain `Hide` there, so `OnHide` (a second `SaveBindings`, `UpdateMicroButtons`) runs tainted too. What a player sees: binding displays (action-button hotkeys, micro-button tooltips) refreshed tainted for the session; no "Interface action failed" proven. All clients. Smallest fix: open the window without closing Blizzard's panel (the stub's own comment already relies on the window showing above it).
2. **Library, Retail and Forever (plausible, Blizzard's API behaviour).** `RowFrames.lua:173` `CreateFrame("DropdownButton", …, "WowStyle2DropdownTemplate")` writes the intrinsic `HandlesGlobalMouseEvent` during the library's insecure `CreateFrame`; a left mouse-down over a dropdown makes `Blizzard_Game/Mainline/EventImplementation.lua:89-136` clear the keyboard focus tainted; with the chat box focused, `ACTIVE_CHAT_EDIT_BOX = nil` is written tainted (`ChatFrameUtil.lua:549-551`). No secure chat command found that reads it before it runs. Every addon with a Blizzard dropdown has it; clearing the field breaks the dropdown's click-to-close. In-game check: chat box focused, click a dropdown, `/dump issecurevariable("ACTIVE_CHAT_EDIT_BOX")`, then `/focus` and `/cast` from chat in and out of combat: a "blocked" message makes it real, none means accept.
3. **KAF, not the library (plausible, a misdirected click).** KAF's Show me overlay (`Options\Window\Help\ShowMe.lua:414-426`) is `DIALOG` level 2, above Blizzard's `SettingsPanel` (`HIGH`, `Blizzard_SettingsPanel.xml:4`): with KAF's window on the Maps help and Blizzard's Options opened over it, a click where Show me was opens the world map and closes KAF's window. Retail and Mists. Smallest fix: release the overlay when `SettingsPanel` or `GameMenuFrame` shows (`HookScript`).
