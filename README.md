An options window for World of Warcraft addons that explains each setting next to the setting itself. Sections are listed on the left, the section's settings in the middle, and a help pane on the right shows the section's explanation or the description of the setting under the mouse. The window looks like the game's own Options window, and several addons can share it, one tab each.

**Alpha:** the API can still change between versions.

## Features
- Check boxes, sliders, dropdowns, buttons, input boxes and key bindings, and check boxes with a button or slider beside them
- Changed settings are marked, with an undo arrow per setting and a reset per section
- Settings that need a reload are marked, with a reload bar
- Search across all sections, on names or also on descriptions
- A help pane with headings, text, terms and pictures
- Its own translations, and safe to embed in several addons at once

## Requirements
- Krowi_Util (KROWI_LIBMAN, with AceLocale)
